# three-tier-architecture-on-aws
AWS Three-Tier Architecture: Designed and implemented a secure, scalable, and highly available web application using AWS VPC, EC2, Application Load Balancer, Auto Scaling, and RDS (MySQL), with separate frontend, application, and database layers.
Used Amazon VPC to create a secure network with public and private subnets across multiple Availability Zones. Configured an Internet Gateway, NAT Gateway, Route Tables, and Security Groups for secure network communication. Deployed application servers on Amazon EC2 in private subnets and used an Application Load Balancer to distribute incoming traffic. Configured Amazon RDS (MySQL) in private database subnets to store application data. Implemented Auto Scaling to maintain application availability and CloudWatch for monitoring.
Technologies Used
- AWS VPC
- Amazon EC2
- Application Load Balancer (ALB)
- Auto Scaling Group
- Amazon RDS (MySQL)
- Internet Gateway
- NAT Gateway
- Security Groups
- Route Tables
- Amazon CloudWatch
Key Responsibilities
1. Designed and implemented AWS three-tier architecture.
2. Created public and private subnets across multiple Availability Zones.
3. Configured secure communication between application and database tiers.
4. Deployed EC2 instances and configured Load Balancer.
5. Integrated EC2 with Amazon RDS MySQL.
6. Configured Auto Scaling for high availability.
7. Monitored AWS resources using CloudWatch.
Project Outcome
Successfully implemented a secure, scalable, and highly available web application architecture on AWS by separating frontend, application, and database components.
